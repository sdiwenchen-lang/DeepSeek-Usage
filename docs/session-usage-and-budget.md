# 会话用量与每日限额

## 已确认范围（2026-11-06）

1. 用量趋势页图表按「Token 用量 → 各模型消费金额 → API 请求次数」排列。
2. Token 卡片提供「会话排行 / 模型走势」，按钮位于标题行最右侧。本地 AI 聚合默认会话排行，DeepSeek 官方模式默认模型走势；会话排行与模型费用排行共用左侧名称、右侧横条和条末数值布局；子会话合并到主会话后按合并总量排序；屏显名称去掉 `session-` 前缀，界面与悬停均不显示会话 ID。官方账单不提供会话归属，会话排行改用同范围的本机会话日志，但只统计涉及当前官方模型（或已选模型）的会话及其对应 Token，标题为「官方模型 · 本机会话 Token」，图下注明本机会话合计与官方账单合计，并说明本统计与官方口径存在差异、以官方账单为准；只展示 Token 与请求次数，不展示预估金额；官方汇总卡与费用图仍只使用官方账单数据。金额图提供「模型排行 / 费用走势」：本地模式默认模型排行，官方模式默认费用走势，与 Token 卡片的模式默认值保持一致。
3. 会话图按当前日期与模型筛选聚合，按 Token 数降序，展示会话标题、Token 数、请求次数；本地模式额外展示预估人民币费用。子会话默认合并到主会话一行，悬停显示包含的子会话数量；找不到主会话记录时单列并在名称前标注「子会话/分叉会话」；分叉继承的历史请求不重复计费。未定价显示「暂无费率」，部分定价标明「部分」。
4. 设置页内嵌每日限额，不另开弹窗、不显示启用开关，也不使用 `*` 帮助；标题采用与「汇率配置」一致的左对齐小标题。Token 与 CNY 采用和汇率配置一致的行式显示：点击当前值进入编辑，失去焦点或按 Enter 自动保存，编辑时行尺寸不变，保存成功不新增状态行；正值即启用，空值/0 表示不限制。Token 须为非负安全整数，CNY 为非负有限数。底部说明注明熔断按当前数据源计算，面板内容固定、不上下滚动；限额用量在说明的悬停标题中查看。
5. 限额跟随当前数据源：本地模式统计当前宿主全部 Provider 的 Token 与本机估算费用，官方模式统计官方账单的 Token 与消费；不受看板日期、模型筛选影响。达到限额后熔断所有 Provider 的后续调用，不控制其他机器、应用或独立宿主进程。
6. 熔断拒绝后续模型调用，包括会话循环、自动续跑、子会话的新调用，并在对应会话中返回「已达到每日限额」的失败原因；已进入供应商的在途请求正常完成。将额度设为零可取消该限额，北京时间每天 00:00 自动按新日用量重新判断，不自动重启先前停止的任务。
7. 2026-11-11 调整：日志读取失败、截断、缺失 usage 或费率时保留统计不完整标志，但已知有效用量达到限额就熔断；已知用量尚未达限或没有有效数值时继续放行。金额须有有效汇率且计价开启。界面明确提示「统计不完整，按已知用量判断限额」。
8. 限额与计价费率保存在宿主配置，重启后有效。浏览器调整费率会同步给宿主；同步失败必须显示提示，不能宣称限额已按新费率生效。
9. 设置顺序：外观、侧边栏标签、定价、每日限额、自动刷新；每日限额在设置页内直接编辑，行式布局与汇率配置一致。外观设置内容整体上移 2px。
10. 侧边栏标签增加可上传图标的简短说明及 `*` 帮助，操作图标支持悬停／聚焦说明；发布描述覆盖会话统计、状态栏自定义和按用量熔断。

## 实现边界

- 数据仍以供应商上报、宿主持久化的会话日志为依据。尚未上报的 in-flight 用量无法预知；并发请求可能使最终消耗超过阈值。
- 普通不带会话记录的模型调用可被统一请求入口拦截，其消耗可能不在本地日志中，无法声称绝对预算保证。
- 清理会话日志会影响可统计的历史用量。
- 宿主配置编辑器不可用时展示错误并禁止保存，不退回只保存在浏览器的假限额。
- 所有更改沿用 React 和现有主题；B Design System 仅参考 32px 控件、14px 正文、6px 输入框圆角、16/24px 留白，未迁移 Vue 或复制模板。

## 验收

- 本地会话图切换后显示真实会话用量；日期/模型筛选同步变化；展示时子会话合并到主会话，找不到主会话时单列，底层统计保留独立会话数据，分叉继承不重复加。
- 会话、模型、时间桶汇总相等，零用量、未定价、部分计价均有明确显示。
- 限额默认不拦截；达到 Token 或金额阈值后 Provider 不被调用；在途请求可完成。
- 跨北京时间零点重新按新日用量判断；输入正值自动启用，设为 0 可取消该额度；重启后读取已保存限额与费率。
- POST 配置仅接受回环同源 JSON，请求体有长度限制，非法输入不落盘。浏览器 GUI 接受宿主配置 origin、请求 Host 推导的同源 origin，以及同协议同端口的其他回环主机名；桌面端 `dsh-app://app/` 的 Electron 代理会删除 Origin/Sec-Fetch-Site 并只带宿主鉴权 cookie，因此无 Origin 但带 cookie 的环回请求按已鉴权同源处理；跨站、`null`、带路径或异源 Origin 仍拒绝。
- 用量不完整但有效部分已达限时仍拦截；未达限或完全不可读时放行，均返回不完整标志。
- 升级与重启保留已保存价格、汇率、隐藏模型及限额；只切数据源不得覆盖较新的限额。浏览器丢缓存后先从宿主恢复价格，再允许编辑。

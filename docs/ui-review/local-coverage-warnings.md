## 修正

- 不再用 `!coverage.complete` 一律显示“部分日志缺失或不可读”。历史缺省 usage 不再产生该常驻提示。
- 实际 `error`、`failed > 0`、`truncated` 仍显示各自具体原因。
- 仅 `unpricedTokens > 0` 时显示未计价提示，避免可选字段缺省造成误报。
- 为以上两个明确模型 ID 增加四通道零费率；Token 与 API 次数保留。自定义价格仍优先，隐藏模型仍按原逻辑处理；付费变体不会继承免费价格。`kilo-auto/free` 保留完整路由键，不让通用 `provider/free` 归一化后误用零费率。
- 不改底层 coverage 与 budget。历史未上报用量仍是未知量，不凭空补零或伪造完整性。

# 用量图表与每日限额 UI 自检

日期：2026-11-06。范围：现有 React 插件的 Token 会话/模型排行、费用排行和设置页内嵌每日限额。

## 基调与首屏骨架

- 字体沿用现有系统字体，金额与 Token 数使用现有等宽数字字体；正文 13–14px，标题 14/18px。
- 色彩沿用当前主题的 `--d-*` 语义变量，与已有五套主题一起变化；新增 UI 未引入独立配色。
- 输入框 6px 圆角、32px 高，新增对话框沿用现有大圆角；16/24px 留白。
- 内容顺序：日期/模型筛选 → 汇总卡 → Token（会话排行/模型走势）→ 消费金额（模型排行/费用走势）→ API 请求。没有新增宣传区或装饰卡。
- 每日限额直接显示在设置页右侧区域，标题采用与「汇率配置」一致的左对齐小标题；Token/CNY 采用与汇率配置一致的行式显示：未编辑时显示当前值，点击数值进入编辑，正值启用、0 或空值不限，失焦或 Enter 触发保存并反馈状态；界面不常驻保存方式提示，也不显示 `*` 帮助。
- 未编辑的限额数值与汇率配置同款按钮样式，单位固定在行尾并使用弱化字色；编辑时替换为行内数字输入，不改变行高。

## 源码与行为检查

- 标题、数值、说明有字重和颜色层次；单位与费用不依赖颜色表达。
- 会话条形复用模型排行模板：左侧会话名称、右侧 Token 比例条，末端显示 Token 与本地估算费用；按 Token 降序、列表有高度限制。本地模式下屏显名称移除 `session-`；子会话默认合并到主会话一行并在悬停标题显示数量，找不到主会话时单列并前置「子会话/分叉会话」标记，不显示 sessionId。设置页内嵌限额沿用汇率配置的 40px 行、圆角与边框，未编辑时显示当前值，点击进入编辑，空值/0 不限。
- 官方模式没有会话维度：会话排行改用同日期范围的本机会话日志，但只保留涉及当前官方模型（或已选模型）的会话，并按这些模型合计 Token；标题为「官方模型 · 本机会话 Token」，图下注明本机会话合计与官方账单合计，并说明本统计与官方口径存在差异、以官方账单为准；只展示 Token 与请求次数，不展示也无法推算官方金额；官方汇总卡与费用图仍只使用官方账单数据。
- 图表条末与悬停总数统一使用 `48M` 这类紧凑格式，避免条末显示 48M、悬停变成完整数字的割裂；精确明细保留在对应模型的费用与请求行。
- 统计不完整使用「⚠」和文字；未知费用显示「暂无费率」，部分计价显示「部分」。
- 会话悬停卡标题使用 12px/500 的正文色，最多两行、超出省略，不再使用 11px 弱化单行；Token 与金额分行展示，数字使用等宽字形。
- Token 卡片本地模式默认会话排行、官方模式默认模型走势；金额图本地模式默认模型排行、官方模式默认费用走势。两个卡片都遵循「排行在前、走势在后」的一致顺序；两组切换按钮在标题行最右侧，窄屏换行后仍右对齐。按钮有可访问名称、`aria-pressed`、键盘焦点；会话排行按钮不再附解释文案，官方模式也可直接切换。
- 侧边栏标签标题旁保留 `*` 帮助；每日限额标题不再显示 `*`，口径与熔断规则直接写在底部说明；工具栏、图标选择器、关闭/翻页按钮补齐用途提示。
- 汇率的显示按钮和编辑输入均居中；设置中每日限额移至定价之后，菜单高亮按稳定标识匹配，内容与高亮不受顺序影响。
- 限额字段有 Token/CNY 标签、非负校验和单位；CNY 上限统一显示两位小数，编辑步进 0.01，超过两位小数提示错误；未编辑时显示当前值，点击进入编辑，正值启用，空值/0 不限；失焦或 Enter 触发保存，串行写入；保存成功不新增状态行，失败显示具体错误，输入区不再常驻「失焦或 Enter 自动保存」提示。宿主存储不可用时禁用输入并说明。
- 每日限额标题不再显示 `*`；Token/CNY 改成与汇率配置一致的行式显示，未编辑时显示当前值，点击数值进入编辑，行高保持不变；聚焦只改边框和内描边，不改变行尺寸，移动端输入字号 16px 避免聚焦自动放大。限额面板保持与其他设置页一致的尺寸，底部熔断说明和错误提示左对齐，底部说明直接位于限额行下方，注明熔断按当前数据源计算；面板内容固定、不上下滚动，限额用量放在说明的悬停标题中。本地模式按本机全部 Provider 估算，官方模式按官方账单；顶部状态栏与侧边栏共享同一份今日快照，Token 与消费格式一致。
- 启用限额后，设置页显示两行限额和底部熔断说明；命中上限时状态条变红并显示「已达到每日限额，后续调用已熔断；次日 00:00 或提高限额后恢复」。统计不完整时增加「统计不完整」提示，对应限额继续放行。
- 设置页内嵌限额区域使用现有设置导航与内容面板，不增加第二层弹窗；焦点随页面输入自然移动，Escape 保留外层面板行为。
- 查询与限额自动保存通过代次控制防止过期请求覆盖较新状态；多个字段的自动保存串行执行。保存错误保留 API 返回原因，成功后用状态文字反馈。
- 限额写请求同时接受「宿主配置 origin」「请求 Host 推导出的精确同源 origin」和同协议同端口的其他回环主机名；桌面端 `dsh-app://app/` 的 Electron 代理转发时会删除 Origin 与 Sec-Fetch-Site，仅保留宿主鉴权 cookie，因此「无 Origin + 有 cookie」的环回请求按已鉴权同源放行。跨站 `Sec-Fetch-Site`、`null`/带路径/异源 Origin、无 cookie 的空白 Origin 仍拒绝。
- 主按钮保存中/成功反馈、视图切换和首次进入有反馈/200–300ms 出场，`prefers-reduced-motion` 下关闭新增动画。
- 新 CSS 均在 `.d-usage` 作用域；新增控件无新依赖，没有复制 Vue 模板，没有修改宿主布局。
- 小屏限额设置沿用汇率配置的行式布局并允许内容滚动，视口变窄时数值与单位仍保持同一行。

## 验证证据与限制

- 插件管理器已将工作区链接安装到当前 desktop profile，返回 `application: applied`；Inspect 确认 `sidebar.footer.action` 中用量入口仍正常注册，配置条目为 `include:deepseek-usage-panel`。

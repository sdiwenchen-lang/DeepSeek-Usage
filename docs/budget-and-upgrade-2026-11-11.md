# 熔断与升级配置保留验收

开始：2026-11-11。续接核验：2026-11-12。范围为每日限额及升级后的价格和已有设置保留。本记录在提交前编写，包版本仍为 0.1.8，本轮不执行 npm 发布。

## 原因与规则修正

原判断要求统计完整才可触发限额。实际本地数据缺少 1 条 usage，虽然有效已统计费用超过 ¥65，仍因 `costComplete=false` 放行。

现规则：有效已知 Token/金额达到对应已启用上限，即拦截后续受控模型调用；保留统计不完整标志。已知用量未达限、完全不可读或没有有效数值时继续放行。金额需要计价开启和有效汇率；已放行的在途请求允许完成。状态 `guardPolicy=known-usage` 表示此规则已加载。

## 价格与设置保留

- 同名模型已保存价格、零费率、自定义模型、汇率和隐藏列表优先；新版默认只补缺。即使用户保存的价格恰好等于当版默认，也不删除显式值。仅主动恢复默认才重置。
- 打开面板先从宿主恢复价格，再允许设置；首次恢复仅读取，不 POST 默认值。宿主从未保存价格时，保留原浏览器旧价格。
- 编辑价格或汇率不会清理其他模型；保存成功后采用宿主返回的完整有效表。请求代次阻止编辑前的旧响应覆盖新价格；失败保留本地编辑并提示用量与限额仍按宿主价格计算。
- 本地用量和对账查询未显式传费率时用宿主已保存费率。宿主价格恢复后，前端查询不再把完整表塞进 URL：142 条价格约 16.9 KB URL 在实际宿主复现 HTTP 431，改用缺省宿主费率避免超长请求。保存成功后重新刷新统计。
- 价格就绪时重建自动刷新定时器；侧边栏等待价格恢复后再首次查询。
- mode-only 写入只改数据源，不能从旧实例回写较早的 Token/CNY 限额；rates-only 不改限额。宿主其他配置保持。
- 侧边栏明确保存的关闭状态、文字、图标和排序不再按“旧默认”猜测重置。主题及自动刷新继续使用原存储键。
- 界面偏好仍在原浏览器/桌面 origin 的 localStorage；插件升级不清除它，但清站点数据、换浏览器或更换 Web 端口不保证恢复这些界面偏好。价格和限额是宿主配置，不依赖浏览器缓存。
